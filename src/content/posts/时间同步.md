# 1.使用 chrony
```shell
# 1.安装 chrony：
dnf install -y chrony

# 2.启动并设置开机自启：
systemctl enable --now chronyd

# 3.如果需要使用特定的 NTP 服务器（如阿里云 ntp.aliyun.com），可以编辑配置文件 /etc/chrony.conf：
vi /etc/chrony.conf
# 修改 server 或 pool 指令，例如：server ntp.aliyun.com iburst
# 保存后，重启服务：
systemctl restart chronyd

# 4.立即强制同步
chronyc -a makestep
```
