# vlan
## vlan 的三种接口模式
### Access
Access 接只服务于一个 VLAN，适用于连接 PC、服务器、打印机等无法处理 Tag 的终端设备。
> __收发规则__
> - __接收：__收到无 Tag 帧 → 打上接口 PVID 的 Tag，收下。收到带 Tag 帧 → 仅当 Tag 中的 VLAN ID 与 PVID 相同时才接收，否则丢弃。
> - __发送：__检查待发送帧的 VLAN ID，仅当它与 PVID 相同时，才剥离 Tag 后发出；不同则直接丢弃。

### Trunk
Trunk 接口用于交换机与交换机、交换机与路由器之间的互联，需要同时承载多个 VLAN 的流量。它的规则比 Access 多一层“白名单”检查。
> __收发规则__
> - __接收：__
>   - 无 Tag 帧 → 打上 PVID 的 Tag；但前提是 PVID 在接口的“允许列表”中，否则丢弃。
>
>   - 带 Tag 帧 → 检查帧的 VLAN ID 是否在允许列表中，在则收下，不在则丢弃。
>
> - __发送：__
>
>   - 帧的 VLAN ID 必须在允许列表中，否则丢弃。
>
>   - 在允许列表中的帧，__仅当 VLAN ID 与 PVID 相同时__，才剥离 Tag 发出；其他 VLAN 的帧一律带 Tag 发出。

### Hybrid
Hybrid 兼具 Access 与 Trunk 的能力，既可以连接终端，也可以连接交换机。它最大的特点在于：可以__独立决定每一个允许通过的 VLAN__，在发出时是否携带 Tag，不受“只能有一个 PVID 剥 Tag”的限制。
> 收发规则
> - __接收：__
>   - 无 Tag 帧 → 打上 PVID 的 Tag；前提是该 PVID 已被允许通过。
>
>   - 带 Tag 帧 → 检查该 VLAN ID 是否在允许通过的列表中，在则收下，不在则丢弃。
>
> - __发送：__规则完全由配置决定。一个 VLAN 可以被配置为 tagged（带 Tag 发出）或 untagged（剥掉 Tag 发出），Hybrid 接口会严格按照配置执行，不自动关联 PVID。

## 常用 vlan 配置命令
### 1. 创建vlan
```bash
[~CE1]vlan 10                                 
[*CE1-vlan10]quit
[*CE1]vlan batch 20 30               # 批量创建 vlan 20 30
[*CE1]vlan batch 40 to 50            # 批量创建 vlan 40、41、42、...、50
```
### 2. 设置接口类型
#### Access
```bash
[CE1-GE1/0/1]port link-type access 
[CE1-GE1/0/1]port default vlan 10    # 将该接口的PVID设为10，并将接口划入VLAN 10
```
#### Trunk

```bash
[CE1-GE1/0/10]port link-type trunk
[CE1-GE1/0/10]port trunk allow-pass vlan 10 20 30
[CE1-GE1/0/10]port trunk pvid vlan 10   # (可选)配置Trunk类型接口的缺省vlan
```
#### Hybrid
```bash
[CE2-GE1/0/10]port link-type hybrid 
[CE2-GE1/0/10]port hybrid untagged vlan 10   # 配置哪些vlan不带标签出
[CE2-GE1/0/10]port hybrid tagged vlan 20 30  # 配置哪些vlan带标签出
[CE2-GE1/0/10]port hybrid pvid vlan 10       # (可选)配置Hybrid类型接口的缺省vlan
```
